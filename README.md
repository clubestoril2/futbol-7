# futbol7-app

Rama desvinculada con la aplicación de calendarios de fútbol 7 del Club
Deportivo Estoril II. Se publica tal cual en GitHub Pages en
<https://futbol7-app.www.clubestoril2.es/>.

- `futbol7.js` y `futbol7.css`: aplicación y estilos.
- `data/index.json`: temporadas disponibles.
- `data/<aaaa-aa>.json`: calendarios de cada temporada. Los actualiza
  automáticamente el flujo «Actualizar datos» de la rama `master`.
- `index.html`: página de ejemplo y comprobación.

La documentación completa está en el `README.md` de la rama `master`.
